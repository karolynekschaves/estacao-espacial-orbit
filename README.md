# Missão Espacial - Módulo de Suporte à Vida

Este projeto contém o sistema de verificação e monitoramento do suporte à vida (`SuporteVida.java`), desenvolvido em Java.

---

## 📌 Descrição das Camadas do Ambiente

O projeto é implantado e mantido em três camadas principais de ambiente de desenvolvimento e produção:

| Ambiente | *Branch* Principal | Descrição |
| :--- | :--- | :--- |
| **Develop** | `develop` | **Ambiente de Desenvolvimento.** Onde novos recursos, correções e testes integrados são desenvolvidos e consolidados antes da validação. |
| **Stage** | `stage` | **Ambiente de Staging / Homologação.** Réplica do ambiente final para testes de aceitação, testes de pré-lançamento e homologação das funcionalidades. |
| **Main** | `main` | **Ambiente de Produção.** Contém o código estável, testado e em uso operacional nas missões ativas. |
